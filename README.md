# [W.I.P.] Zero Panel

> [!IMPORTANT]
> This project is very early into development and a lot of code is also still private,
> as this grows I will accept contributions and issues at a later stage.
> Documentation is still being worked on.

Zero is a service management panel meant for deploying services, games, and other
general-purpose workloads. It's written in Go and SvelteKit and has a sleek and
intuitive UI with a focus on flexibility, speed and security at the forefront.

## Developing

### Starting the dev environment

```sh
docker compose up
```

and to start the web-server:

```sh
bun run dev
```
